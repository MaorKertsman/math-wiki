# הנחיות לעריכת ויקי מתמטיקה

## כלל תצוגת נוסחאות — display math למשוואות ארוכות

נוסחאות מתמטיות ארוכות או מורכבות חייבות להיות בבלוק `$$...$$` (display math) ולא inline `$...$`. נוסחה inline בתוך טקסט עברי מפריעה לקריאה ומקשה על הבנה.

### מתי להשתמש ב-`$$...$$`

| סוג | דוגמה | כלל |
|-----|-------|-----|
| משוואה עיקרית / תוצאה | `$V=\bigoplus W_i$` | תמיד display |
| נוסחה עם `\sum`, `\prod`, `\bigoplus`, `\bigcup` | `$\sum_{i=1}^n a_i$` | תמיד display |
| נוסחה עם `\frac` | `$\frac{f(x)}{g(x)}$` | תמיד display |
| נוסחה עם `\ker`, `\mathrm{Im}`, `\det` בהקשר מרכזי | `$\ker g_i(T)$` | display אם היא הנקודה המרכזית |
| שרשרת שוויונות / גרירות | `$A \iff B \iff C$` | תמיד display |
| נוסחה ארוכה (מעל ~25 תווים) | כל ביטוי מורכב | display |

### מתי inline `$...$` מותר

סמלים קצרים בתוך משפט: `$f$`, `$\lambda$`, `$T:V\to V$`, `$n$`, `$W_i$` — אלה נשארים inline.

## כלל RTL — כל משפט מתחיל במילה עברית

אובסידיאן קובע כיוון טקסט לפי התו הראשון בפסקה. כדי לקבל RTL, **כל משפט/שורת פרוזה חייבת להתחיל בתו עברי**.

### תבנית תיקון לשורות שמתחילות ב-`$`

| שורה בעייתית | תיקון |
|---|---|
| `$f$ גזירה ב-...` | `הפונקציה $f$ גזירה ב-...` |
| `$A$ לכסינה אם...` | `המטריצה $A$ לכסינה אם...` |
| `$\lambda$ נקרא ע"ע...` | `הסקלר $\lambda$ נקרא ע"ע...` |
| `$v\neq 0$ נקרא וקטור עצמי...` | `וקטור $v\neq 0$ נקרא וקטור עצמי...` |
| `$x_0$ היא נקודת קיצון...` | `הנקודה $x_0$ היא נקודת קיצון...` |
| `$S\subseteq A$ מקיימת...` | `הקבוצה $S\subseteq A$ מקיימת...` |
| `$I$ אינו ריק...` | `האידיאל $I$ אינו ריק...` |
| `$f,g$ נקראים זרים...` | `הפולינומים $f,g$ נקראים זרים...` |
| `$A=\begin{pmatrix}...` | `תהי $A=\begin{pmatrix}...` |
| `$\blacksquare` (שורה בפני עצמה) | `■` (תו Unicode ישיר, ללא LaTeX) |

בלוקי `$$...$$` הם מתמטיקה בתצוגה — אין צורך לשנותם.

## מבנה דף ויקי סטנדרטי

```markdown
---
tags:
  - math/<קורס>/<סוג>
aliases:
  - <שם חלופי>
---

# <כותרת הדף>

## הגדרה  (או: הטענה / המשפט)

<תוכן פורמלי — כל משפט מתחיל במילה עברית>

## הוכחה

<הוכחה — שורות הוכחה מתחילות במילה עברית>

## הערות (אופציונלי)

<הערות, דוגמאות נגדיות, הכללות>

## ראה גם

- [[קישור לדף קשור]]
```

## בניית דפי ויקי מהרצאה

### עקרונות

1. **ישות אחת לדף** — כל הגדרה, משפט, או למה מקבלים דף נפרד.
2. **שם קובץ = שם הישות בעברית** — למשל `גזירות.md`, `משפט לגרנז.md`.
3. **קישורים פנימיים** — כל מושג עם דף משלו מקושר עם `[[...]]`.
4. **פרק "ראה גם"** — מחבר לכל הגדרה/משפט שמשמשים בהוכחה.

### תבנית הגדרה

```markdown
---
tags: [math/<קורס>/definitions]
aliases: [<שם>, <שם נוסף>]
---

# <שם>

## הגדרה

<ניסוח פורמלי>

## ראה גם

- [[ישות קשורה]]
```

### תבנית משפט/טענה

```markdown
---
tags: [math/<קורס>/claims]
aliases: [<שם>]
---

# <שם>

## הטענה

<ניסוח פורמלי>

## הוכחה

<הוכחה>

## ראה גם

- [[הגדרה שנדרשת בהוכחה]]
```

### מעבר מהרצאה לויקי — סדר הפעולות

1. זהה את כל ההגדרות החדשות בהרצאה → דף הגדרה לכל אחת.
2. זהה את כל המשפטים/למות → דף טענה לכל אחד.
3. ודא שכל מושג שמוזכר בהוכחה מקושר עם `[[...]]`.
4. בדוק שכל שורת פרוזה מתחילה בתו עברי (כלל RTL).
5. הוסף `aliases` לכל שמות חלופיים נפוצים.
6. עדכן את דף הקורס (`ליניארית/ראשי.md` / `אינפי/ראשי.md` וכו') — הוסף את הדפים החדשים לפרק המתאים.
7. עדכן את `index.md` (דף הבית הראשי) — הוסף את הדפים החדשים לאינדקס המלא תחת הקורס הנכון.
